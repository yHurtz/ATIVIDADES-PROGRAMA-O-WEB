# Minha Página Pessoal

## Sobre o projeto

Este projeto foi desenvolvido como atividade da disciplina de Programação Web I. A página apresenta informações pessoais, minha formação acadêmica e algumas tecnologias que conheço.

## Tecnologias utilizadas

- HTML5
- C++
- Java
- MySQL

## Objetivo

Praticar a estrutura básica do HTML, utilizando títulos, parágrafos, listas e links.
