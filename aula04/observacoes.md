# Observações sobre elementos HTML

## Elementos de bloco (block)

- **h1:** título principal da página. É um elemento de bloco.
- **h2:** título de uma seção. É um elemento de bloco.
- **h3:** título de menor nível que o h2. É um elemento de bloco.
- **p:** representa um parágrafo. É um elemento de bloco.
- **ul:** cria uma lista não ordenada. É um elemento de bloco.
- **ol:** cria uma lista ordenada. É um elemento de bloco.

## Elementos de linha (inline)

- **a:** cria um link para outra página ou seção. É um elemento inline.
- **strong:** destaca um texto com importância semântica. É um elemento inline.
- **img:** exibe uma imagem na página. É um elemento inline por padrão.

## Experimentos com elementos HTML

### Dois elementos strong

Quando usamos dois elementos `strong` no mesmo parágrafo, ambos destacam os textos com importância semântica, sem iniciar um novo bloco.

### Dois elementos p

Quando usamos dois elementos `p` consecutivos, cada parágrafo ocupa seu próprio bloco, ficando separado do outro visualmente.

## Conclusão

Os elementos de bloco normalmente começam em uma nova linha e ocupam o espaço disponível. Os elementos inline ficam no fluxo do texto, ocupando apenas o espaço necessário ao seu conteúdo.
